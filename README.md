# Edificaciones · Estudio

Sitio de estudio interactivo para **Edificaciones** (especificaciones técnicas y procesos constructivos), pensado para PC y celular.

Cada tema incluye:

- **Guía** con las cifras para memorizar y el paso a paso, con esquemas.
- **Diagramas** SVG con huecos para completar.
- **Tarjetas** de repaso (flashcards).
- **Practicar**: verdadero/falso, opción múltiple, completar, ordenar pasos y emparejar, con explicación.
- **Prueba** tipo examen con puntaje y repaso de errores.

El progreso se guarda solo en el navegador (localStorage). Tema claro/oscuro con el botón de la esquina.

> Material basado en los apuntes de clase. Herramienta de estudio no oficial: manda lo que diga el documento del docente.

Sitio estático, sin dependencias: abrir `index.html` con cualquier servidor estático (`python -m http.server`).
